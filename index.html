LOCAL-FIRST

Your study data stays close.

There are no accounts, analytics, or note uploads. Desktop stores notes in SQLite; Web stores them in IndexedDB. Export backups before clearing application or browser data.

Offline by design

Documentation and notes remain useful without a network connection.

Honest boundaries

Web has no terminal access. Windows uses external terminals. Playground isolation is defense-in-depth, not a perfect sandbox.

FAQ

One product, two entry points.

What is the difference between Desktop and Web?

Desktop supports downloadable docsets, native storage, exports, and developer tools. Web is a small, installable browser trial with starter documentation.

Can I use the terminal in the browser?

No. The Developer Terminal is a desktop feature. Linux embeds a normal user shell; Windows opens the user's external terminal tools.

Is ZealRN affiliated with Zeal?

ZealRN is based on Zeal but independently maintained and not officially endorsed by the upstream project.
